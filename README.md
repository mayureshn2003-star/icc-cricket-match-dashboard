# 🏏 Official ICC Tournament Analytics Dashboard

A real-time and historical cricket analytics web application built with **Streamlit**, **Plotly**, and **Python**. This dashboard strictly filters live cricket feeds to focus exclusively on official **ICC Tournaments** (e.g., T20 World Cup, ODI World Cup, WTC, Champions Trophy).

---

## ✨ Features

- **🔴 Live ICC Match Feeds:** Real-time data integration via CricAPI, automatically filtered to display official ICC events only.
- **📜 Classic ICC Match Archive:** Built-in historic database featuring major ICC finals and semi-finals.
- **📈 Interactive Visualizations:**
  - **Cumulative Score Progression:** Line charts comparing over-by-over run trajectories.
  - **Manhattan Charts:** Bar charts displaying run outputs for every over.
  - **Partnership Analysis & Wicket Breakdown:** Detailed player pairing stats and interactive donut charts.
- **🎨 Custom Dark Theme:** Optimized Streamlit UI layout with high-contrast metrics.

---

## 🚀 Tech Stack

- **Frontend / Framework:** [Streamlit](https://streamlit.io/)
- **Data Plotting:** [Plotly Express & Graph Objects](https://plotly.com/python/)
- **Data Handling:** [Pandas](https://pandas.pydata.org/)
- **API Requests:** [Requests](https://requests.readthedocs.io/)
